# Employee Record Management System in PHP and MySQL

## Project Overview

The Employee Record Management System is a web-based application developed using PHP and MySQL. It is designed to store, manage, and maintain employee-related information in an organized manner.

The system provides two main user roles:

1. Admin
2. User or Employee

All the functionalities mentioned below can be completed using PHP, MySQL, HTML, CSS, JavaScript, and Bootstrap. The project does not require any third-party API or advanced functionality.

---

# Admin Functionality

## 1. Admin Login

The admin can log in to the system using a registered username or email address and password.

The system will:

* Validate the admin credentials
* Display an error message for incorrect credentials
* Create a login session after successful authentication
* Redirect the admin to the dashboard
* Prevent unauthorized users from accessing admin pages

## 2. Admin Dashboard

The admin dashboard will display a summary of the records available in the system.

The dashboard may show:

* Total number of employees
* Total number of departments
* Total active employees
* Total inactive employees
* Recently added employees
* Recently updated employee records

## 3. Manage Departments

The admin can manage different departments of the organization.

The admin can:

* Add a new department
* View all departments
* Edit department details
* Delete a department
* Search for a department
* Check whether a department already exists before adding it

Example departments include:

* Human Resources
* Finance
* Information Technology
* Marketing
* Sales
* Administration

## 4. Add Employee

The admin can register a new employee in the system.

The employee form may include:

* Employee ID
* Full name
* Father’s name
* Gender
* Date of birth
* Email address
* Mobile number
* Address
* Department
* Designation
* Date of joining
* Salary
* Employment status
* Profile photograph
* Username
* Password

The system will validate required fields before saving the employee record.

## 5. View Employee List

The admin can view all registered employees in a table.

The employee list may display:

* Employee ID
* Employee name
* Department
* Designation
* Email address
* Mobile number
* Joining date
* Employment status
* Available actions

The available actions may include:

* View
* Edit
* Delete
* Activate or deactivate

## 6. View Employee Details

The admin can open the complete profile of an employee.

The employee details page may show:

* Personal information
* Contact information
* Employment information
* Department
* Designation
* Salary details
* Joining date
* Profile photograph
* Current employment status

## 7. Update Employee Record

The admin can modify an existing employee record.

The admin can update:

* Name
* Email address
* Mobile number
* Address
* Department
* Designation
* Salary
* Date of joining
* Employment status
* Profile photograph
* Other personal details

The updated information will be saved in the MySQL database.

## 8. Delete Employee Record

The admin can delete an employee record that is no longer required.

Before deleting the record, the system should display a confirmation message.

After confirmation:

* The employee record will be removed from the database
* The employee will no longer be able to log in
* The deleted record will not appear in the employee list

## 9. Search Employee

The admin can search for an employee using:

* Employee ID
* Employee name
* Email address
* Mobile number
* Department
* Designation

The matching employee records will be displayed in the results.

## 10. Filter Employee Records

The admin can filter employee records according to:

* Department
* Designation
* Employment status
* Gender
* Joining date

This functionality will help the admin find specific employee records easily.

## 11. Activate or Deactivate Employee

The admin can change the account status of an employee.

The employee account can be marked as:

* Active
* Inactive

An inactive employee will not be allowed to log in to the system.

## 12. Manage Designations

The admin can manage employee designations.

The admin can:

* Add a designation
* View designations
* Edit designation names
* Delete designations

Example designations include:

* Manager
* Accountant
* Software Developer
* Sales Executive
* Office Assistant
* HR Executive

## 13. Manage Employee Salary Details

The admin can store and update basic salary information for employees.

The admin can:

* Add employee salary
* Update salary amount
* View employee salary
* Search salary records
* View salary according to department or employee

This minor project can maintain only the basic salary amount without implementing a complete payroll system.

## 14. Manage Employee Documents

The admin can upload and manage basic employee documents.

Documents may include:

* Resume
* Identity proof
* Address proof
* Educational certificate
* Joining letter

The admin can:

* Upload documents
* View document names
* Download documents
* Delete documents

Only local file upload functionality will be used.

## 15. View User Feedback or Requests

Employees can submit basic requests or messages to the admin.

The admin can:

* View employee requests
* Read request details
* Update request status
* Delete resolved requests

Request status may include:

* Pending
* In Progress
* Resolved

## 16. Change Admin Password

The admin can change the current password.

The admin must enter:

* Current password
* New password
* Confirm new password

The system will verify the current password before saving the new password.

## 17. Update Admin Profile

The admin can update basic profile information such as:

* Name
* Email address
* Mobile number
* Username
* Profile photograph

## 18. Generate Basic Employee Report

The admin can view a simple employee report containing:

* Employee ID
* Employee name
* Department
* Designation
* Joining date
* Salary
* Employment status

The report can be displayed in a printable webpage format.

## 19. Logout

The admin can securely log out from the application.

After logout:

* The admin session will be destroyed
* The admin will be redirected to the login page
* Protected pages will no longer be accessible

# User or Employee Functionality

## 1. Employee Login

The employee can log in using a username or email address and password provided during registration.

The system will:

* Validate login credentials
* Check whether the employee account is active
* Create an employee session
* Redirect the employee to the user dashboard
* Show an error message for invalid credentials

## 2. Employee Dashboard

The employee dashboard will display basic information related to the logged-in employee.

The dashboard may show:

* Employee name
* Employee ID
* Department
* Designation
* Joining date
* Employment status
* Profile photograph

## 3. View Personal Profile

The employee can view personal and employment information stored in the system.

The profile may include:

* Full name
* Employee ID
* Gender
* Date of birth
* Email address
* Mobile number
* Address
* Department
* Designation
* Date of joining
* Employment status
* Profile photograph

## 4. Update Personal Details

The employee can update selected personal information.

The employee may update:

* Mobile number
* Email address
* Address
* Profile photograph

Important employment details such as salary, department, designation, joining date, and employee ID should only be updated by the admin.

## 5. View Department and Designation

The employee can view the currently assigned:

* Department
* Designation
* Joining date
* Employment status

The employee cannot directly modify these details.

## 6. View Salary Information

The employee can view the basic salary amount entered by the admin.

The employee can only view the salary information and cannot edit it.

## 7. View Uploaded Documents

The employee can view the list of documents stored in the profile.

The employee may:

* View document names
* Download available documents
* Check uploaded document details

Document deletion or replacement may remain under admin control.

## 8. Submit Request or Feedback

The employee can submit a request or message to the admin.

The request form may contain:

* Request subject
* Request description
* Request date
* Request status

Example requests include:

* Correction in personal details
* Department update request
* Document update request
* Salary information correction
* General query

## 9. View Request Status

The employee can view submitted requests and their current status.

The status may be:

* Pending
* In Progress
* Resolved

The employee can also view the submission date and request description.

## 10. Change Password

The employee can change the account password.

The employee must provide:

* Current password
* New password
* Confirm new password

The system will verify the current password before updating it.

## 11. Logout

The employee can securely log out of the system.

After logout:

* The employee session will be destroyed
* The employee will be redirected to the login page
* Employee pages will not be accessible without logging in again

# Common System Functionality

## 1. Role-Based Login

The system will identify whether the logged-in account belongs to an admin or employee.

Based on the role:

* Admin will access the admin panel
* Employee will access the employee panel

## 2. Session Management

PHP sessions will be used to maintain user login.

The system will prevent users from opening protected pages without authentication.

## 3. Form Validation

All forms will validate the entered data.

Validation may include:

* Required field validation
* Valid email format
* Valid mobile number
* Password confirmation
* Duplicate employee ID checking
* Duplicate email checking
* File type validation
* File size validation

## 4. Password Security

Passwords should not be stored as plain text.

PHP password functions can be used:

* `password_hash()` for storing passwords
* `password_verify()` for checking passwords

## 5. Confirmation Messages

The system will display confirmation or error messages after actions such as:

* Employee added successfully
* Employee updated successfully
* Employee deleted successfully
* Invalid login credentials
* Password changed successfully
* Request submitted successfully

## 6. Responsive User Interface

The application interface can be developed using Bootstrap so that it works properly on:

* Desktop computers
* Laptops
* Tablets
* Mobile devices
