Directory Management System Using PHP and MySQL

A Directory Management System is a web-based application used to store, organize, search, and manage contact or directory records. The project can be developed using PHP, MySQL, HTML, CSS, JavaScript, and Bootstrap.

The following functionality is suitable for a college minor project and can be completed without using third-party APIs or advanced features.

Admin Functionality
1. Admin Login
Admin can log in using a registered username or email and password.
The system validates the entered login details.
Incorrect login details display an error message.
Only authenticated administrators can access the admin dashboard.
Admin can log out securely.
2. Admin Dashboard

The dashboard displays a summary of the directory system, such as:

Total registered users
Total directory records
Total categories
Recently added directory records
Recently registered users
3. Manage Directory Categories

Admin can create and manage categories used to organize directory records.

Examples:

Educational Institutions
Hospitals
Government Offices
Restaurants
Hotels
Shops
Service Providers
Emergency Contacts
Personal Contacts

Admin can:

Add a new category
View all categories
Edit category name and description
Delete a category
Activate or deactivate a category

Before deleting a category, the system should check whether directory records are connected to it.

4. Add Directory Records

Admin can add a new directory entry with the following details:

Person or organization name
Category
Contact person name
Mobile number
Alternate mobile number
Email address
Address
City
State
Postal code
Description
Status
Created date

The system validates required fields before saving the record.

5. View Directory Records

Admin can view all directory records in a table.

The table can display:

Record ID
Name
Category
Mobile number
Email
City
Added by
Status
Created date
Available actions

Admin can open any record to view its complete details.

6. Edit Directory Records

Admin can update existing directory information, including:

Name
Category
Phone number
Email address
Address
City
State
Description
Status

The updated information is stored in the database.

7. Delete Directory Records
Admin can delete unnecessary or incorrect directory records.
A confirmation message appears before deletion.
After confirmation, the selected record is removed from the database.
8. Search Directory Records

Admin can search directory records using:

Name
Category
Mobile number
Email address
City
State

The system displays only the records matching the entered search value.

9. Filter Directory Records

Admin can filter records according to:

Category
Status
City
Date added
User who added the record
10. Manage Registered Users

Admin can view all registered users with details such as:

User ID
Full name
Username
Email address
Mobile number
Registration date
Account status

Admin can:

View user details
Edit basic user information
Activate a user account
Deactivate a user account
Delete a user account
11. Approve User-Submitted Records

When a user adds a directory record, it can initially be saved with a Pending status.

Admin can:

View pending submissions
Review record details
Approve the record
Reject the record
Edit the record before approval

Only approved records should appear in the public directory.

12. Manage Contact Messages

Users can submit messages through a contact form.

Admin can:

View received messages
View sender name, email, subject, and message
Mark messages as read
Delete messages
13. Manage Admin Profile

Admin can:

View profile information
Update name
Update username
Update email address
Change password

The current password should be verified before saving a new password.

14. Change Password

Admin must enter:

Current password
New password
Confirm new password

The system verifies that the new password and confirmation password match before updating it.

15. Logout
Admin can log out from the system.
The admin session is destroyed.
The admin is redirected to the login page.
User Functionality
1. User Registration

A new user can create an account by entering:

Full name
Username
Email address
Mobile number
Password
Confirm password

The system should:

Validate required fields
Check whether the email already exists
Check whether the username already exists
Verify that both passwords match
Save the user information in the database
2. User Login
Registered users can log in using their email or username and password.
The system checks whether the account is active.
Invalid credentials display an error message.
Successful login redirects the user to the user dashboard.
3. User Dashboard

The user dashboard can display:

Total records added by the user
Approved records
Pending records
Rejected records
Recently added records
4. Browse Directory

Users can browse all approved directory records.

Each directory record can show:

Name
Category
Phone number
Email address
Address
City
State
Description

Only active and approved directory records should be displayed.

5. Search Directory

Users can search for directory records using:

Person name
Organization name
Category
Mobile number
City
State

The search results display matching records.

6. Filter Directory Records

Users can filter directory records by:

Category
City
State

This makes it easier to find relevant information.

7. View Directory Details

Users can open a directory record to view its complete information.

The detailed page can contain:

Name
Category
Contact person
Mobile number
Alternate number
Email address
Complete address
City
State
Postal code
Description
8. Add Directory Record

A logged-in user can submit a new directory record.

The user enters:

Name
Category
Contact person
Mobile number
Alternate number
Email address
Address
City
State
Postal code
Description

After submission:

The record is stored with a pending status.
Admin reviews the record.
The record becomes visible after approval.
9. View My Submitted Records

Users can view the directory records submitted from their accounts.

The list displays:

Record name
Category
Mobile number
Submission date
Approval status
Available actions

Possible statuses:

Pending
Approved
Rejected
10. Edit Submitted Records

Users can edit their own records when they are pending or rejected.

Users cannot edit records submitted by other users.

After editing an approved record, the system may change its status back to pending for admin review.

11. Delete Submitted Records
Users can delete records submitted by them.
A confirmation message appears before deletion.
Users cannot delete records belonging to other users.
12. Manage User Profile

Users can:

View profile
Update full name
Update username
Update email address
Update mobile number

The system should prevent duplicate usernames and email addresses.

13. Change Password

Users can change their passwords by entering:

Current password
New password
Confirm new password

The current password must be verified before saving the new password.

14. Contact Admin

Users can submit a contact message containing:

Name
Email address
Subject
Message

The message is saved in the database and becomes available in the admin panel.

15. Logout
User can log out securely.
The user session is removed.
The user is redirected to the login page.
