# Email Setup for Password Reset

## 1. Create `.env` file

Copy `.env.example` to `.env` and fill in your values:

```
EMAIL_BACKEND=django.core.mail.backends.smtp.EmailBackend
EMAIL_HOST=smtp.gmail.com
EMAIL_PORT=587
EMAIL_USE_TLS=1
EMAIL_HOST_USER=your-email@gmail.com
EMAIL_HOST_PASSWORD=your-app-password
```

## 2. Gmail Setup

1. Enable **2-Step Verification** on your Google account
2. Go to https://myaccount.google.com/apppasswords
3. Create an **App Password** (16 characters, no spaces when you copy it)
4. Use that 16-character password in `EMAIL_HOST_PASSWORD`

**Important:** Use the App Password, NOT your normal Gmail password.

## 3. `.env` Format

- **No spaces** around `=`
- **No quotes** unless the value has spaces
- If password has spaces, use: `EMAIL_HOST_PASSWORD="your app password"`

## 4. Restart Server

After changing `.env`, **restart** the Django server:
```bash
# Stop the server (Ctrl+C) then:
python manage.py runserver
```

## 5. Test Email

Run in Django shell:
```bash
python manage.py shell
```
```python
from django.core.mail import send_mail
send_mail('Test', 'Body', 'from@example.com', ['your-email@gmail.com'], fail_silently=False)
```

If you see an error, check the message for details.

## 6. Fallback: File Backend

If SMTP fails, use file backend to get reset links from the `emails/` folder:

```
EMAIL_BACKEND=django.core.mail.backends.filebased.EmailBackend
```

Remove or comment out EMAIL_HOST, EMAIL_HOST_USER, EMAIL_HOST_PASSWORD when using file backend.
