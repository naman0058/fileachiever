# MindCare — Mental Health Chatbot (ML + Flask)

MindCare is a web application that combines a **mental wellness chatbot**, **mood tracking**, **self-assessments**, and an **admin panel** to manage users, training data, and ML models. Chat replies use **local training data and NLP/ML** by default; **OpenAI** can optionally be enabled in code for AI-generated responses.

> **Disclaimer:** This is a demonstration and support tool. It is **not** a substitute for professional mental health care or emergency services.

## Machine Learning & Algorithms

### Text preprocessing (`app/ml/preprocess.py`)

- Lowercasing, URL removal, non-letter stripping  
- **NLTK**: tokenization, English **stopword** removal, **Porter stemming** (WordNet avoided for stability under Flask reload)

### Feature extraction & classification (`app/ml/train.py`, `app/ml/predict.py`)

- **TF–IDF vectorization** (`TfidfVectorizer`, up to 5,000 features, **1–2 gram** n-grams)  
- **Logistic regression** (`class_weight="balanced"`) in a **scikit-learn `Pipeline`**

Two models are trained and saved with **joblib** under `ml_models/`:

1. **Intent classifier** — labels such as greeting, stress, sadness, anxiety, loneliness, sleep issue, etc.  
2. **Emotion classifier** — labels such as happy, sad, stressed, anxious, neutral, etc.

### Reply selection (`app/services/chat_service.py`)

- **Pattern-first matching**: if a **training pattern** appears in the user message (longest match wins), that row’s response is returned.  
- Otherwise: random choice among rows matching **intent**, then **emotion**, then **neutral**.  
- **Keyword heuristics** in `predict.py` override obvious misclassifications (e.g. stress before greeting when the user says they are overwhelmed).

### Model training

- Triggered from **Admin → Training data → Train / retrain ML models**, or by running `seed_database.py` (which trains after seeding).  
- Requires at least **two** rows in the `training_data` table.

## How to Run the Project

### 1. Prerequisites

- **Python 3.10+** (3.12 recommended)  
- `pip`

### 2. Clone / open the project folder

```bash
cd "path/to/Mental HEalth Chatbot Using ML"
```

### 3. Create a virtual environment (recommended)

```bash
python -m venv .venv
.venv\Scripts\activate          # Windows
# source .venv/bin/activate     # macOS / Linux
```

### 4. Install dependencies

```bash
pip install -r requirements.txt
```

### 5. Environment file (optional)

Create a `.env` file in the **same folder as `config.py`** (project root):

```env
SECRET_KEY=your-secret-key-for-production
OPENAI_API_KEY=
OPENAI_MODEL=gpt-4o-mini
```

OpenAI is **optional** and currently **commented out** in `app/routes/chat.py`. To enable it, uncomment the `generate_reply` import and the `generate_reply(...)` call, and set `OPENAI_API_KEY`.

### 6. Seed the database (first time)

```bash
python seed_database.py
```

This creates the SQLite DB, demo users, admin, training rows, quotes, etc., and trains the initial ML models.  
**Re-seed:** delete `mental_health.db` (and optionally `ml_models/*.joblib`) then run `seed_database.py` again.

If the DB already has an admin, the script **skips** seeding (see console message).

### 7. Start the server

```bash
python run.py
```

Open a browser: **http://127.0.0.1:5000**

## Troubleshooting

- **NLTK data**: First run may download NLTK resources (punkt, stopwords); ensure internet access once.  
- **Port in use**: Change the port in `run.py` or run `flask run --port 5001`.  
- **Wrong chat replies**: Add/edit **training_data** in admin; use **pattern-first** phrases; click **Train / retrain ML models**.  
- **Logout issues**: Logout uses **POST**; ensure JavaScript is enabled for the nav form.
